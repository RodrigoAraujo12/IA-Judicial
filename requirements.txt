# --- acelerador opcional (nao instalar junto) --------------------------------
# `onnxruntime-directml` SUBSTITUI a wheel acima, nao soma a ela: as duas
# fornecem o modulo `onnxruntime`. So Windows, e so vale a pena com GPU.
#
#     pip uninstall -y onnxruntime && pip install onnxruntime-directml
#

# PRIMEIRA da maquina custa ~15 s compilando shaders, depois o driver cacheia).
# Os vetores sao intercambiaveis com os da CPU (cosseno 0,9999999), entao da
# para indexar numa maquina e consultar noutra. O codigo detecta sozinho: sem o
# pacote, `provedores()` devolve so CPU e nada muda.
